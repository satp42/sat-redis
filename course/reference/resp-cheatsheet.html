RESP cheat sheet

The RESP2 wire format sat-redis speaks, the Python value each type becomes, and the rules a parser must not break.

Commands vs replies

DirectionShapeExample
client → serveralways an array of bulk stringsGET user:42 → *2\r\n$3\r\nGET\r\n$7\r\nuser:42\r\n
server → clientany typePING → +PONG\r\n, GET missing → $-1\r\n, INCR n → :1\r\n

Parser rules

RuleWhy
Bulk data ends where the length says, not at \r\nValues may contain \r\n or any byte (binary-safe)
Incomplete → None, never an errorrecv may stop anywhere inside a frame
Garbage → ProtocolErrorWaiting will not fix it: reply with an error and close
Return the bytes used, leave the restThe next frame may already be in the buffer (pipelining)
$0\r\n\r\n is b"", $-1\r\n is NoneAn empty value and a missing key must look different
